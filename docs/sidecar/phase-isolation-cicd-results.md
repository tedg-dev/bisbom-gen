## Objective

Prove that Phase 1 (build + manifest) and Phase 2 (SPDX generation)
can run in **completely separate GitHub Actions jobs** on **different
runners** with **no shared filesystem**, communicating only via
artifact upload/download. This validates the enterprise deployment
model where Phase 1 runs at the customer build site and Phase 2 runs
in a separate analysis service.

## Toggle Mechanism

The sidecar jobs are conditional:

```yaml
if: >-
  (github.event_name == 'workflow_dispatch' && inputs.enable_sbom) ||
  (github.event_name != 'workflow_dispatch' && vars.OMNIBOR_ENABLED != 'false')
```

- **Push/PR**: runs unless `vars.OMNIBOR_ENABLED` is set to `'false'`
- **Manual**: `workflow_dispatch` with `enable_sbom` boolean input
- **Baseline job**: always runs regardless of toggle
